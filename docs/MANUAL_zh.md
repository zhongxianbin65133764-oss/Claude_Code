# Polymarket 套利助手 · 使用手册

> 给"看得懂中文、但没写过代码"的人看的版本。

## 1. 这是什么?

一个**自动盯着 Polymarket(美国一个预测市场网站)、找便宜货、自动下单**的小程序。

它专门做**一种**生意:
- Polymarket 上每个"问题"都是一张"彩票"
- 比如"湖人会赢这场比赛吗?"——选"会赢"的彩票在比赛打完之前大概值 50 美分
- 比赛打完湖人真赢了,这张彩票理论值就涨到 1 美元
- 但 Polymarket 上的官方"裁判"(叫 UMA)要花 1-7 天才确认结果,这段时间里,
  这张"已经知道答案"的彩票常常**还在 95-96 美分卖**
- 程序就在这段空窗期**自动用 95 美分买进,等几天兑成 1 美元**,赚中间几分钱差价

**这不是预测,也不是赌博。是耐心+自动化套小利**。

- ❌ 加密钱包(同上)

程序的第一步会自动测一下你这边能不能联上,**如果不能联,这套东西在你那边就跑不了**,需要 VPN 或换境外服务器。

## 4. 五分钟装上(全程复制粘贴)

### 第 1 步:打开终端

按 **Cmd + 空格**,输入 **"终端"**,回车。会弹出一个黑色窗口。
所有代码都在这个窗口里粘贴 + 回车运行。

### 第 2 步:下载代码

复制下面这行,粘贴进终端,回车:

```bash
git clone https://github.com/<你的用户名>/Claude_Code.git
cd Claude_Code
git checkout claude/polymarket-automation-research-rSrmY
```

> 如果终端说 "command not found: git",装一下 Xcode 工具:
> 在终端运行 `xcode-select --install`,弹窗里点"安装",等几分钟。

### 第 3 步:测一下能不能联上 Polymarket

```bash
python3 scripts/check_network.py
```

会看到类似这样的输出:

```
  Gamma  (market discovery)        OK  83 ms
  CLOB   (orderbook reads)         OK  695 ms
  Coinbase candles (oracle)        OK  159 ms
  Polygon RPC (orders)             OK  120 ms

  ✓ Dry-run ready.
```

**前两行 OK 就够了**(Gamma + CLOB)。

如果看到 `BLOCKED 403`,就是你的 IP 被屏蔽了——这种情况下需要先开 VPN,
连一个美国/日本/香港之外的国家(比如荷兰、德国、台湾)再重试。

### 第 4 步:一键启动

```bash
./scripts/mac/mac_start.sh
```

这个脚本会:
1. 自动复制配置文件(默认是"演练模式",不花真钱)
2. 安装需要的 Python 库(几分钟)
3. 启动机器人 + 看板
4. **自动打开浏览器到 http://localhost:5000**

成功后,你会在浏览器看到一个像股票账户一样的页面,这就是看板。

## 5. 看板上每个数字什么意思?

### 顶部:大字盈亏

```
        已结算盈亏(实盘预估)
              +$5.20
   共 12 笔已结清 · 单笔平均 +1.7%
   如果完美执行,理想盈亏会是 +$12.50,
   实盘缩水了 $7.30
```

**这是核心数字**:从机器人启动到现在,**估计你会赚多少 / 亏多少钱**。

- **绿色**(+) = 在赚钱
- **红色**(−) = 在亏钱
- **灰色**(—) = 还没结清第一笔

下面那行小字"理想盈亏 vs 实盘缩水"是诚实告诉你:**"如果你 100% 完美下单,本该赚这么多;但实际上因为各种摩擦,实盘只能赚这么多"**。

### 三个小卡片

```
  ┌──────────────┬─────────────────┬─────────────────┐
  │ 正在持有     │ 还在场上的钱    │ 总成本(实盘) │
  │   3 笔       │   $48.50        │   $112.30       │
  └──────────────┴─────────────────┴─────────────────┘
```

- **正在持有**:已经买了但还没结算的彩票张数
- **还在场上的钱**:这些没结算的彩票一共花了多少钱(锁在场上)
- **总成本**:已经结清的所有交易花的总钱数

### "演练 vs 实盘的差距"小节

```
  发现机会     实际抢到       资金捕获率     平均价格漂移
   45 次       28 次 (62%)    51%            +1.2¢
```

**这部分超级重要,它告诉你"演练数据有多接近真实情况"**:

- **发现机会**:机器人看到了多少个"看起来便宜"的市场
- **实际抢到**:其中真的能买到的数量(60-70% 算正常,低于 40% 说明竞争太激烈)
- **资金捕获率**:想买 $100 实际能买多少 $(50% 算正常)
- **平均价格漂移**:从看到机会到下单完成这 60 秒里,价格往上跑了多少(0-2¢ 正常)

### 折线图:盈亏走势

- **绿色实线**:实盘预估 — **你真去交易实际会赚多少**
- **灰色虚线**:理想 — 如果完美执行的赚多少

两条线分得越开,说明**实盘越难做**。如果实线在零线下面,**这个策略当前赚不到钱**。

### 两张表

- **正在持有**:每个未结算的彩票,你下了多少钱,等了多久
- **已经结清**:每个结算了的彩票,理想赚多少,实盘赚多少,等了多久

每行的"押的方向":
- 🟢 **会发生**:押"是会发生"
- 🔴 **不会发生**:押"否,不会发生"

### 底部的"这个看板是什么意思?"

是个**可以点开**的折叠区,解释术语和原理。看不懂某个数字时点开看。

## 6. 第一周该期待什么?

### 头三天

- **可能没有任何交易**——这是正常的
- 套利窗口其实**很窄**:北京时间早上 8-10 点(币价收盘)+ 晚上 22 点至凌晨 4 点(美国体育)
- 其他时段大部分是垃圾市场(温度、政治、奇怪小众),机器人会全部跳过
- 这时候大字盈亏会显示 "—"(没有结清的交易)

**这是好事**——保守 abstain 比乱买亏钱强。

### 第四到第七天

- 应该开始看到几笔结清的交易
- 大字盈亏会从灰色变成绿色或红色
- 折线图会开始有形状

### 一周末

```bash
# 在终端运行(项目目录里)
python3 scripts/weekly_review.py
```

会输出一份**周复盘报告**,告诉你:
- 一周捕捉了多少机会
- 钱主要亏在哪(部分成交 / 逆向选择 / UMA 改判)
- 哪些子类目赚 / 哪些亏
- 下一步该改什么

把这份报告**保存或发给懂行的朋友**,根据建议调整 `.env` 配置。

## 7. 什么时候该担心?

| 看到什么 | 含义 | 该怎么办 |
|---|---|---|
| 一周内连一笔机会都没发现 | 网络问题 或 当前市场太冷清 | 跑 `check_network.py` 确认网络;查看 `data/bot.log` 看有没有报错 |
| 实盘预估 30 天内持续亏 | 策略在当前市场不赚钱 | 跑周复盘,按建议调阈值;或者暂停一阵 |
| UMA 改判率超过 5% | 子类目里有不该交易的市场 | 跑周复盘,把高争议子类目从白名单去掉 |
| Mac 突然变慢 | 几乎不可能(程序很轻量) | 检查 `top` 看是不是别的应用在吃 CPU |
| 看板打不开 | 程序挂了 | 终端运行 `./scripts/mac/mac_start.sh` 重启 |

### 黄牌警告(检查但不一定有问题)

- ⚠️ 折线图掉头向下三天 — 看复盘,可能是策略适应期
- ⚠️ 资金捕获率<30% — 网络延迟太高,或者别的 bot 太多
- ⚠️ 实盘预估比理想差>50% — 摩擦太严重,要调参数

### 红牌(立刻处理)

- 🚨 你升级到了实盘模式(`DRY_RUN=false`)但 **从来没看过看板** → **立刻 Ctrl+C 关掉,先空跑一周**
- 🚨 看板上出现 "true LIVE TRADING" 但你不记得开过 → 立刻终止,检查 `.env`
- 🚨 钱包余额突然清零 → Polymarket 已经地区封号了

## 8. 常见问题

### Q1: 真的能赚钱吗?

**诚实答案**:不一定。这个策略数学上有正期望,但取决于:
- 当前 Polymarket 上有多少"安全的便宜货"(取决于市场)
- 别的套利 bot 多不多(取决于运气)
- 你的网络延迟和参数调得多准(取决于你)

**保守预期**:**演练一个月后再决定要不要上实盘**,实盘起步 $100-200。
如果第一个月就开始上千美元,99% 会后悔。

### Q2: Mac 关机会怎样?

- **关机**:程序停止,数据库保留。重新开机后跑 `./scripts/mac/mac_start.sh` 恢复
- **睡眠**:如果用 Docker 或 LaunchAgent 不影响;原生 Python 路径有 `caffeinate` 防睡眠
- **重启**:同关机

**推荐**:用 `./scripts/mac/install_launchd.sh` 注册成系统服务,从此 Mac 一开机就自动起。

### Q3: 程序会不会瞎下单?

**不会**。默认配置:
- `DRY_RUN=true` — **空跑模式,不下任何真实订单**
- 即便手动改成 false,有一堆保护:每笔最多 $25、总仓位最多 $200、政治市场不碰、UMA 高争议关键词全部拒绝

要想真下单,必须**主动**:
1. 改 `.env` 里 `DRY_RUN=false`
2. 提供钱包私钥
3. 提供 Polymarket API 三件套

**前面两步不主动做,绝对动不了真钱**。

### Q4: 我数据会被发到哪去吗?

**程序只读 Polymarket、Coinbase 的公开 API**,把数据存在你 Mac 上的 `data/positions.db`。
没有数据上传到任何第三方服务器。

但请注意:如果你设了 `DRY_RUN=false`,你的下单请求会到 Polymarket(显然),
你的钱包地址会在 Polygon 链上公开可见(这是区块链的本质)。

### Q5: 我能让朋友看我的看板吗?

可以。Docker 路径默认 `0.0.0.0:5000` 监听,**同一 WiFi 下的手机/平板**可以访问:

1. Mac 上跑:`ifconfig | grep "inet " | grep -v 127`,记下类似 `192.168.x.x` 的地址
2. 手机浏览器打开 `http://192.168.x.x:5000`

⚠️ 不要把端口暴露到公网(没有密码)。

### Q6: 怎么彻底删干净?

```bash
./scripts/mac/uninstall_launchd.sh    # 移除系统服务
./scripts/mac/mac_stop.sh             # 停 Python 进程
docker-compose down 2>/dev/null       # 停 Docker(如果用了)
cd .. && rm -rf Claude_Code           # 删项目目录
```

钱包还在你那里,只要不动它就什么钱都没花。

### Q7: 我看到"BLOCKED 403"怎么办?

Polymarket 屏蔽了你的 IP。三个选项:

1. **VPN**:Surfshark / NordVPN / 自建 WireGuard,连一个**不在屏蔽名单**的国家
   (荷兰、德国、台湾、日本测试过有效;**不要选**美国、英国、新加坡、法国)
2. **境外 VPS**:在 DigitalOcean / Hetzner / Linode 开一个 $5/月的小机器,
   在那上面跑(用 Docker 路径)
3. **放弃,继续学习**:即便没法实盘,你也能看代码学习套利逻辑

### Q8: 一定要 Docker 吗?

不一定。`./scripts/mac/mac_start.sh` 会自动判断:
- 如果你装了 Docker Desktop → 用 Docker(更稳定)
- 如果没装 → 用原生 Python(更轻量)

两个都能用,**Docker 推荐用于长期 7×24 跑**。

## 9. 让它自动起来(可选)

设置好之后,把程序注册成 macOS 系统服务,**每次 Mac 开机自动跑、崩了自动重启**:

```bash
./scripts/mac/install_launchd.sh
```

执行后会显示:

```
✓ Installed com.polymarket-arb.bot.plist
✓ Installed com.polymarket-arb.dashboard.plist

Useful commands:
  Check status :  launchctl list | grep polymarket-arb
  View logs    :  tail -f data/bot.log data/dashboard.log
  Dashboard    :  open http://localhost:5000
  Uninstall    :  ./scripts/mac/uninstall_launchd.sh
```

**完成**。从现在开始你不用管它,Mac 开机就自动跑。
每隔几天打开浏览器 http://localhost:5000 看看就行。

不想要了:`./scripts/mac/uninstall_launchd.sh`,**会自动清理**。

## 10. 我应该怎么用这套东西?

### 阶段 A:学习期(第 1-7 天)

- ✅ 跑起来,每天打开看板看 5 分钟
- ✅ 第三天跑一次 `live_smoke_test.py` 看一眼当时市场啥样
- ✅ 第七天跑 `weekly_review.py` 看周报
- ❌ 不动 `.env`,不上实盘,不投真钱

### 阶段 B:校准期(第 8-30 天)

- ✅ 根据周复盘调阈值
- ✅ 看看实盘预估是不是开始稳定向上
- ✅ 思考是否打开 `event_moneyline` 子类目
- ❌ 仍然不上实盘

### 阶段 C:小额试水期(第 31-60 天)

只有满足以下**全部**条件才进入这个阶段:
- 演练数据一个月,**实盘预估**累计正收益
- 周复盘建议都执行了
- 你**完全理解**每个数字含义
- 你愿意亏掉 $100-200 当学费

那时候:
1. 在 Polymarket 开账号 + API key
2. 创建一个**全新的、独立的**钱包(别用你日常用的)
3. 转入 $100-200 USDC
4. 改 `.env` 的 `DRY_RUN=false`
5. 启动看板等 10 秒倒计时

### 阶段 D:常态运行(第 61 天+)

每周看一次复盘,根据数据调整。

**绝大多数人不会到 D 阶段**。**学到东西就够本了**,不一定要上实盘。
