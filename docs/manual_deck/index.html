FAQ · 第 8 节摘录

四个关键问题

真的能赚钱吗?
不一定。数学期望为正,但取决于当前市场上有多少"安全的便宜货",别的套利 bot 多不多,你的网络延迟。保守预期:演练一个月再决定要不要上实盘。
Q1
Mac 关机会怎样?
关机:程序停,数据库保留。建议用 LaunchAgent 注册成系统服务,Mac 开机就自动起。
Q2
程序会不会瞎下单?
不会。默认 DRY_RUN=true 完全不下单。即便手动改成 false,有单笔 $25 + 政治市场不碰 + UMA 高争议关键词全拒等多层保护。
Q3
看到 BLOCKED 403?
Polymarket 屏蔽了你的 IP。三个选项:VPN 连不在屏蔽名单的国家 / 境外 VPS / 放弃实盘,继续学习。
